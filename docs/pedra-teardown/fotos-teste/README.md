## Furos conhecidos

1. **Sem "mesmo cômodo, 2 ângulos".** O teste de consistência (bloco 2 do prompt v2) fica
   fraco só com stock. Ideal: 2 fotos reais de um cômodo só, ou pule esse bloco.
2. **Sem quarto vazio de verdade.** Staging de quarto ≈ staging de sala, então não é
   crítico. Se quiser, baixe um em pexels.com/search/empty%20bedroom.
3. **`F_foto_escura.jpg` é escurecida artificialmente**, não é foto ruim de celular real.
   Aproxima, mas não é idêntico ao caso real.
4. **`G` é uma varanda à noite.** Se quiser área externa diurna, troque.
